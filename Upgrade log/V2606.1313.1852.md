# 更新日志 V2606.1313.1852

## 更新概述

本次更新主要优化了系统配置管理和首次运行体验，包括：
- 配置文件从 JSON 格式迁移到 PHP 格式，提高安全性
- 新增首次安装引导流程
- 修复转码记录文件初始化问题

## 更新内容

### 1. 配置文件安全升级

**问题**: JSON 配置文件中的敏感信息（如数据库密码）可被直接下载

**解决方案**: 将配置存储从 JSON 格式迁移到 PHP 格式

**优势**:
- PHP 配置文件无法被直接下载（Web 服务器会执行而非返回源码）
- 敏感信息不会被直接暴露
- 即使文件被访问，PHP 也会先执行再输出

### 2. 新增首次安装引导流程

**新增文件**: [install.php](file:///e:/GitHub/FFmpegPHP/install.php)

**功能说明**:
- 首次运行时自动检测配置文件是否存在
- 如果不存在，自动重定向到安装页面
- 用户完成配置后提交，自动创建配置文件并进入系统
- 安装页面包含基础设置和数据库设置两个选项卡

### 3. 转码记录文件优化

**问题**: `ting.json` 文件首次为空时，可能出现记录失败的情况

**解决方案**:
- 在安装完成后自动创建默认的 `ting.json` 文件
- 在 `data` 目录下预置空数组 `[]`

**修改文件**:
- [install.php](file:///e:/GitHub/FFmpegPHP/install.php) - 安装成功后创建 `ting.json`
- [data/ting.json](file:///e:/GitHub/FFmpegPHP/data/ting.json) - 预置空数组

## 兼容性说明

- 系统优先读取 `data/config.php`
- 如果存在旧的 `data/config.json`，系统会继续使用（兼容旧版本）
- 建议通过设置页面保存一次配置，以生成 PHP 格式的文件

## 安全优势

1. PHP 配置文件不能被直接下载
2. 敏感信息（数据库密码）不会被直接暴露
3. 首次安装流程确保系统配置完整后才能使用
4. 默认转码记录文件避免首次记录失败
