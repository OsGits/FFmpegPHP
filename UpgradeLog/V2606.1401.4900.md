### 4. PHP 函数配置说明

**新增章节**: README.md 中的"PHP 函数禁用配置"

**说明内容**:
列出系统运行所需的 PHP 函数，确保这些函数未被禁用：

| 函数名 | 用途 |
|--------|------|
| `exec()` | 执行 FFmpeg 命令行工具 |
| `file_exists()` | 检查文件或目录是否存在 |
| `file_get_contents()` | 读取文件内容 |
| `file_put_contents()` | 写入文件内容 |
| `mkdir()` | 创建目录 |
| `unlink()` | 删除文件 |
| `rename()` | 重命名/移动文件 |
| `copy()` | 复制文件 |
| `iconv()` | 字符编码转换（支持中文文件名） |
