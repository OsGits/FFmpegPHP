# 转码系统数据库功能升级日志

## 升级日期
2026年6月11日

## 升级内容

### 1. 数据库操作增强
**文件**: `mysql/database.php`

- 添加了数据库启用状态检查
- 增强了错误处理机制，返回详细的错误信息和错误码
- 优化了 `saveVideoInfo()` 方法的返回格式

### 2. 转码流程集成数据库写入
**文件**: `includes/functions.php`

- 在 `process_single_file()` 函数中添加了完整的数据库保存逻辑
- 转码完成后自动将视频信息写入 MySQL 数据库
- 添加了详细的调试日志，便于排查问题
- 在转码结果页面显示数据库保存状态（成功/失败/未启用）

### 3. 配置文件统一管理
**文件**: `data/config.json`

- 统一使用 `data/config.json` 作为配置文件
- 支持以下数据库配置项：
  - `mysql_enabled`: 是否启用数据库（1=启用，0=禁用）
  - `mysql_host`: 数据库服务器IP地址
  - `mysql_port`: 数据库端口（默认3306）
  - `mysql_db`: 数据库名称
  - `mysql_user`: 数据库用户名
  - `mysql_password`: 数据库密码
  - `m3u8_full_url`: m3u8文件的完整访问链接

### 4. 数据库表结构
**表名**: `vodm3u8`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键，自增 |
| vodmc | VARCHAR(255) | 视频名称（不含扩展名） |
| vodimg | VARCHAR(255) | 截图URL |
| vodurl | VARCHAR(255) | m3u8播放链接 |
| vodsj | VARCHAR(50) | 视频时长 |
| voddx | VARCHAR(50) | 文件大小 |
| created_at | TIMESTAMP | 创建时间 |

## 使用说明

1. **启用数据库功能**:
   - 访问设置页面 → 数据库选项卡
   - 勾选"是否启动数据库"
   - 填写数据库连接信息
   - 点击"测试连接"验证配置
   - 保存设置

2. **转码自动写入数据库**:
   - 配置完成后，每次转码完成会自动将视频信息写入数据库
   - 转码结果页面会显示数据库保存状态

3. **查看数据库状态**:
   - 转码成功后页面会显示：
     - 🟢 绿色：数据库保存成功（显示记录ID）
     - 🔴 红色：数据库保存失败（显示错误原因）
     - 🟠 橙色：数据库功能未启用

## 注意事项

- 确保 MySQL 数据库中存在 `vodm3u8` 表（可通过设置页面的"测试连接"自动创建）
- 数据库用户需要有 INSERT 权限
- 确保 `data/config.json` 文件有写入权限
