# 更新日志 V2606.1402.0949

## 更新概述

本次更新新增了**在线更新功能**，用户可以直接在系统中检测新版本并一键更新，无需手动下载上传。

## 更新内容

### 1. 在线更新功能

**新增文件**: [update.php](file:///e:/GitHub/FFmpegPHP/update.php)

**功能特性**:
- 自动从 GitHub 下载最新版本压缩包
- 自动创建备份到 `data/backup/` 目录
- 自动解压并安装更新文件
- 实时进度显示和状态提示

**保护机制**:
- 配置文件 (`data/config.php`) 不会被覆盖
- 用户数据 (`vodoss/`, `m3u8/`) 不会被影响
- 转码记录 (`data/ting.json`) 会被保留
- 所有更新前自动创建备份

**权限要求**:
- `data/` 目录必须可写
- 主要 PHP 文件必须可写
- 如果权限不足，系统会提示解决方案

**界面展示**:
- 显示当前版本和最新版本对比
- 显示最新版本的更新说明（changelog）
- 更新前显示警告提示和备份信息
- 更新过程显示动画和状态文字
- 支持更新成功/失败反馈

### 2. 版本信息界面优化

**修改文件**: [index.php](file:///e:/GitHub/FFmpegPHP/index.php)

**优化内容**:
- 从 `version.json` 统一读取版本信息
- 显示当前版本和最新版本对比
- 检测到新版本时显示 "[有更新]" 提示（红色）
- 已是最新版本时显示 "[已是最新]" 提示（绿色）
- 检测到更新时同时显示"在线更新"和"离线下载"两个按钮

**按钮样式**:
- "在线更新"按钮：绿色背景，点击进入自动更新流程
- "离线下载"按钮：灰色背景，跳转到 GitHub 下载页面

### 3. 版本信息集中管理

**配置文件**: [version.json](file:///e:/GitHub/FFmpegPHP/version.json)

**配置说明**:
所有版本相关链接统一在 `version.json` 中管理，便于维护：

```json
{
    "version": "V2606.1402.0949",
    "release_date": "2026-06-14",
    "download_url": "https://github.com/OsGits/FFmpegPHP/releases",
    "changelog_url": "https://github.com/OsGits/FFmpegPHP/tree/main/UpgradeLog",
    "github_repo": "https://github.com/OsGits/FFmpegPHP",
    "github_api": "https://api.github.com/repos/OsGits/FFmpegPHP/releases/latest",
    "author": "OsGits",
    "license": "MIT"
}
```

**配置项说明**:

| 字段 | 说明 |
|------|------|
| `version` | 当前版本号 |
| `release_date` | 发布日期 |
| `download_url` | GitHub 下载页面地址 |
| `changelog_url` | 更新日志页面地址 |
| `github_api` | GitHub API 地址，用于检测最新版本 |

## 使用指南

### 检测更新

1. 访问系统首页
2. 查看"版本信息"卡片
3. 系统自动从 GitHub 获取最新版本
4. 如果有更新，会显示红色"[有更新]"提示

### 在线更新

1. 在版本信息区域点击绿色的"在线更新"按钮
2. 进入更新页面，查看更新说明
3. 点击"确认更新"开始自动更新
4. 等待更新完成（系统会自动创建备份）
5. 更新成功后返回首页

### 离线更新

1. 在版本信息区域点击灰色的"离线下载"按钮
2. 跳转到 GitHub 下载页面
3. 下载最新版本的压缩包
4. 手动解压覆盖原文件（注意保留 `data/config.php`）

## 备份说明

更新时系统会自动创建备份，备份文件保存在：

```
data/backup/backup_YYYYMMDDHHMMSS.zip
```

**备份内容包括**:
- 所有 PHP 文件
- 样式和脚本文件
- 配置文件以外的 JSON 文件

**备份不包括**:
- `data/config.php`（用户配置）
- `data/ting.json`（转码记录）
- `vodoss/`（待转码视频）
- `m3u8/`（转码输出）

## 故障排除

### 权限不足

**错误提示**: `data 目录不可写，无法创建备份`

**解决方案**:
```bash
# 通过 SSH 创建备份目录
mkdir -p data/backup

# 设置目录权限
chmod 755 data/backup
chmod 755 data
```

### 网络连接失败

**错误提示**: `无法连接到 GitHub，请检查网络`

**解决方案**:
- 检查服务器是否能访问外网
- 检查防火墙是否阻止了 GitHub
- 使用"离线下载"方式手动更新

### 更新后显示异常

**解决方案**:
1. 清除浏览器缓存
2. 强制刷新页面（Ctrl+F5）
3. 检查浏览器控制台是否有错误
