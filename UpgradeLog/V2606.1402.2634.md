## 权限说明

在线更新功能需要目录具有写入权限：

| 权限要求 | 说明 |
|----------|------|
| **777** | 完全读写执行权限（推荐） |
| **775** | 组内读写执行权限 |
| **755** | 读执行权限（部分服务器可用） |

**设置命令**:
```bash
# 通过 SSH 设置权限
chmod -R 777 /www/wwwroot/你的网站目录

# 或仅设置必要目录
chmod -R 777 /www/wwwroot/你的网站目录/data
```
